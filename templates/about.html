About LoanPredict AI

A machine learning-based web application designed to demonstrate how applicant and financial information can be used for loan eligibility prediction.

What is LoanPredict AI?

LoanPredict AI is a Machine Learning classification project that predicts whether a loan application is likely to be approved or rejected. The system collects applicant information through a web interface, processes the information using Python and Flask, and uses a trained Logistic Regression model to generate a prediction.

Project Objective

To demonstrate the complete workflow of a Machine Learning application — from collecting input data and processing features to generating predictions and storing results in a database.

🤖

Machine Learning

Uses Logistic Regression for binary classification of loan application outcomes.

⚡

Instant Prediction

Applicant information is processed and a prediction is generated through the Flask web application.

🗄

Prediction History

Previous predictions are stored locally using an SQLite database for later review.

Technology Stack

The project combines machine learning, backend development, database management, and frontend technologies.

Python Flask Scikit-learn Logistic Regression Pandas NumPy SQLite HTML5 CSS3 Bootstrap JavaScript

How the System Works

The application follows a simple machine learning prediction pipeline:

Applicant Data User Input
→
Data Processing Feature Preparation
→
ML Model Logistic Regression
→
Prediction Approved / Rejected
→
SQLite Store Result
Educational Project: This application is created for academic and educational purposes. Its predictions should not be treated as actual banking, lending, or financial decisions.
